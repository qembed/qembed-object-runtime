# SQLx offline metadata

This directory stores the query metadata generated by `cargo sqlx prepare`.

There are currently no SQLx query macros in the workspace, so no query metadata
JSON files are expected yet. When compile-time checked SQL queries are added,
run `cargo sqlx prepare` against the development PostgreSQL database and commit
the generated files in this directory. CI verifies the metadata with
`cargo sqlx prepare --check` and then compiles with `SQLX_OFFLINE=true`.
